Clicker (정각 원클릭) - 사용 안내
=================================

[준비]
- Python 3.10 이상을 설치하세요: https://www.python.org/downloads/windows/
  설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크하세요.

[실행]
- zip 압축을 먼저 풀고, 폴더 안의 Clicker.bat을 더블클릭하세요.
  (zip 안에서 바로 실행하면 동작하지 않습니다.)
- "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]을 누르세요.

[사용 순서]
1. [마우스로 좌표 지정] -> 클릭할 위치를 한 번 클릭 (ESC: 취소)
2. 실행 시각을 분까지 입력 (예: 2026-10-25 15:00). 초와 밀리초는 0으로 고정됩니다.
3. 필요하면 "앞당김" 값을 정하세요 (기본 20ms, 0~1000ms).
   입력한 시각보다 그만큼 먼저 클릭합니다. 입력칸 아래에 실제 클릭 시각이 표시됩니다.
4. [예약 시작] -> 확인 창에서 [확인]

[서버 시간]
- 프로그램을 켜면 시간 서버(NTP)에 자동으로 접속해 서버 시각을 확인합니다.
  "상태 확인"에 서버 시각, PC 시각, 그리고 PC가 서버보다 몇 ms 빠르거나 느린지가 표시됩니다.
- "서버 시간 기준으로 실행"이 켜져 있으면 입력한 시각을 서버 시각으로 보고,
  PC 시계 차이를 자동으로 보정해서 클릭합니다. 끄면 PC 시계 기준으로 실행합니다.
- 기본 시간 서버는 한국표준과학연구원(KRISS)의 time.kriss.re.kr 입니다.
  응답이 없으면 time2.kriss.re.kr 등 다른 서버를 고르세요.
- 시간 서버는 목록에서 고르거나 직접 입력할 수 있습니다.
  예약 직전에 [서버 시간 동기화]를 한 번 더 눌러 주면 가장 정확합니다.

[주의]
- 이 버전은 "실제 클릭" 모드로 켜집니다.
  처음에는 "드라이런" 체크를 켜고 [5초 후 테스트]로 먼저 확인해 보세요.
- [5초 후 테스트]는 확인 창에서 [확인]을 누른 때부터 5초 후에 클릭합니다.
- 앞당김을 너무 크게 하면 버튼이 열리기 전에 클릭될 수 있습니다.
- 클릭할 위치가 결제/삭제 같은 버튼이 아닌지 먼저 확인하세요.
- 서버 시각은 표준 시간 서버 기준입니다. 클릭할 사이트의 서버 시계와는
  조금 다를 수 있습니다.
- 실행 기록은 같은 폴더의 click_log.txt에 자동으로 저장됩니다.
- 사이트 이용약관과 자동화 제한을 지켜서 사용하세요.
